| Purpose Convert each Bolt Shorts idea into a controlled, retention-engineered production package: topic gate, hook variants, transcript, storyboard, scene prompts, edit map, rejection criteria, and analytics feedback. Built from analysis of the supplied 900K- and 1.9M-view reference Shorts, plus lessons from the ocean-depth production iterations.

## 1. Executive Summary
| The operating rule One simple transformation. A visually complete new consequence every 3–5 seconds. A fundamentally new story world every 10–15 seconds. Every claim must remain understandable with the sound muted. |
| --- |


The reference Shorts do not win because they are short. They run approximately 70 and 81 seconds, yet sustain attention by continuously changing the viewer’s question. Each scene delivers a small reward—failure, joke, scale reveal, physical transformation, advantage, reversal, or new danger—before opening the next question.
- Do not optimize only for runtime. Optimize for meaningful novelty and scene value.
- Do not build a sequence of facts. Build a chain of visible consequences.
- Do not let Bolt stand beside information. Make Bolt interact with the world.
- Do not use labels as evidence. Show the physical event the label describes.
- Maintain one predictable governing rule while making its consequences difficult to predict.
- Treat every finished Short as an experiment whose analytics update the next spec.

| v1 emphasis | v2 addition |
| --- | --- |

| Linear escalation | World changes and premise resets |

## 2. Source-Derived Viral Reference Learnings
### 2.1 The opening is a promise stack
The reference videos use the opening seconds to preview multiple forms of payoff rather than presenting a title and waiting for the story to begin. The opening should communicate visual range: consequence, novelty, and vulnerability.
| Opening beat | Function | Required test |
| --- | --- | --- |
| Image 1 | Immediate premise consequence | Readable in under 0.7 seconds |
| Image 2 | Strangest later-stage outcome | Expands the perceived scale of the video |
| Image 3 | Bolt’s vulnerability or comic failure | Creates emotional investment |
| Story start | Return to the beginning or governing rule | Creates a clear forward journey |


| Do not confuse preview with spoiler Show the range of consequences without revealing the final conceptual answer. The viewer should know the journey will be eventful but still need the explanation and final reversal. |
| --- |


### 2.2 Every scene is a mini-payoff
A scene is not valuable merely because it adds information. Each scene must produce a complete viewer reward and then create the next open loop.
| Reward type | What it looks like |
| --- | --- |
| Visible failure | Bolt tries something and cannot complete it |
| Unexpected advantage | The transformation briefly helps Bolt |
| Reversal | The advantage becomes a danger |
| Scale reveal | A familiar object becomes enormous, tiny, heavy, or fragile |
| Physical transformation | Bolt or an object visibly changes state |
| Visual joke | A recognizable daily activity becomes absurd |
| New threat | A normal object or animal becomes dangerous |
| Conceptual payoff | The real mechanism differs from the obvious explanation |


### 2.3 Familiar objects do the explaining
The strongest scenes translate abstract numbers into daily-life interactions. Viewers should not need to calculate what a number means; the environment should demonstrate it.
| Abstract claim | Weak treatment | High-retention treatment |
| --- | --- | --- |
| Bolt is half normal size | Height label changes | Bolt cannot reach a car pedal or door handle |
| Gravity doubles | Gauge reaches 2G | Bolt’s chair collapses when he tries to stand |
| Body becomes gold | Gold texture applied | Bolt breaks furniture, sinks, and attracts thieves |
| Pressure rises | Depth number increases | Suit seam bends inward and a valve fails on screen |


### 2.4 Story worlds prevent list fatigue
A numeric progression is not automatically a story progression. A new world changes the operating rules, objects, environment, objective, or threat—not merely the label.
| World threshold | Example shift |
| --- | --- |
| Normal world | The transformation begins inside ordinary daily life |
| Inconvenience world | Common tasks become difficult or funny |
| Threshold world | Bolt must adopt a new strategy or environment |
| Hostile world | Ordinary objects or animals become threats |
| Final world | The transformation exposes its deepest consequence or paradox |


### 2.5 Emotional modulation resets attention
Danger-only escalation becomes tonally flat. Strong Shorts alternate shock, humor, curiosity, inconvenience, wonder, reversal, and danger.
| Time band | Recommended emotional role |
| --- | --- |
| Opening | Shock or absurdity |
| Early | Curiosity and clear rule |
| Early-middle | Humor or recognizable inconvenience |
| Midpoint | Surprise or temporary advantage |
| Late-middle | Reversal into danger |
| Climax | Awe, destruction, or unsettling payoff |
| Final beat | Memorable conceptual line or loop |


## 3. Additional Upgrades Beyond the Reference Learnings
The following mechanisms extend the viral-reference observations into a more rigorous production system.
### 3.1 Open-loop chaining
Do not rely on one question for the whole Short. Each scene should answer the previous question while opening a smaller next question. Example: “Can Bolt still walk?” → “Can his heart still pump?” → “What fails before he is crushed?”
### 3.2 Retention debt
Every explanatory sentence creates retention debt. Repay it with a visible payoff within approximately two seconds. Avoid two consecutive explanatory sentences without a transformation, collision, failure, reveal, or joke.
### 3.3 Surprise budget
Reserve at least three consequences that are not obvious from the title. The premise may be predictable; the exact consequences must not be.
### 3.4 Character objective
Give Bolt a concrete objective inside the premise—reach a door, drive home, finish breakfast, escape the room, protect an object. A goal converts a demonstration into a story.
### 3.5 Failure chain
Each scene should damage Bolt’s ability to achieve the objective. The failures must compound rather than reset at every scene.
### 3.6 Advantage-to-disadvantage reversal
Include at least one moment where the transformation appears beneficial before turning against Bolt. This breaks tonal and structural predictability.
### 3.7 Thumbnail-to-first-frame continuity
The first moving frame should immediately validate the title and thumbnail promise. Avoid a mismatch where the title promises catastrophe but the video opens with a calm setup.
### 3.8 Audio pattern interrupts
Use sound to mark structural changes, not every edit. Strategic silence, sudden bass removal, perspective shifts, impact sounds, and distorted audio can reset attention more effectively than constant whooshes.
### 3.9 Hook-variant testing
Generate three different 2.5-second hook concepts before rendering the full Short: catastrophe, absurd comparison, and mystery/reversal. Select the strongest using a dedicated hook score.
### 3.10 Animatic gate
Build a low-cost timed animatic from still frames, temp voiceover, captions, and sound cues. Reject predictable or unreadable sections before expensive video generation.
### 3.11 Mute-first QA
Review the animatic and final render without sound first. The story should remain at least 80% understandable from action, object relationships, transformation, scale, and captions.
### 3.12 Scene-value pruning
A scene that repeats the same consequence category, emotional beat, composition, or information type must be combined, replaced, or cut—even when scientifically accurate.
## 4. Topic Qualification Gate
Do not write the transcript until the idea passes the topic gate. Score each criterion from 0 to 5. Minimum production score: 25/30. A score below 3 in First-Frame Action or Consequence Variety is an automatic rejection.
| Criterion | 0–1 | 3 | 5 |
| --- | --- | --- | --- |
| One-sentence clarity | Requires explanation | Understandable with context | Instantly understandable |
| First-frame action | Static premise | Some visible change | Immediate dramatic action |
| Personal stakes | Abstract/world-only | Bolt affected indirectly | Bolt/viewer physically affected |
| Consequence variety | Same result repeated | Several categories | Many distinct daily-life consequences |
| World-change potential | Single environment | One meaningful reset | Multiple operating-rule changes |
| Final payoff | Expected answer | Useful answer | Surprising mechanism or reversal |


| High-potential topic pattern Transformation + measurable progression + familiar daily-life consequences + bodily or environmental stakes. Examples: gravity increases, Bolt shrinks, strength rises, senses disappear, body material changes, time accelerates. |

## 5. Strategic Brief
| Field | Required content |
| --- | --- |
| Working title | Plain-language promise with one clear transformation |
| Core question | The single question the viewer believes the video will answer |
| One-sentence answer | The scientifically defensible answer |
| Governing rule | The one transformation that remains consistent |
| Bolt’s objective | What Bolt is trying to accomplish during the Short |
| Primary retention mechanism | Escalation, thresholds, countdown, transformation, pursuit, or mystery |
| Three hidden consequences | Non-obvious scenes reserved for the middle and final third |
| Final reversal/payoff | The deepest or counterintuitive answer |
| Scientific assumptions | Scenario boundaries, units, and simplifications |
| Target runtime range | Derived from scene value, not fixed by habit |


## 6. Hook Development and Selection
### 6.1 Generate three hook variants
| Variant | Structure |
| --- | --- |
| Catastrophe hook | Show Bolt experiencing a late-stage failure while the question is spoken |
| Absurd comparison hook | Use a familiar object interaction that instantly proves the transformation |
| Mystery/reversal hook | Show an outcome that appears to contradict the premise |


### 6.2 Hook score
| Dimension | Weight | Question |
| --- | --- | --- |
| First-frame readability | 20 | Can a viewer understand the event before hearing the narration? |
| Motion/shock | 20 | Does meaningful action begin immediately? |
| Premise clarity | 20 | Does the visual validate the title? |
| Range promise | 15 | Does the opening imply multiple distinct later consequences? |
| Bolt emotion | 15 | Is Bolt’s reaction physically legible? |
| Open question | 10 | What remains unresolved after 2.5 seconds? |


Minimum hook score: 80/100. Do not render the full Short until one hook passes.

## 9. Transcript Specification
- Start mid-action or with a direct consequence. No greeting, channel introduction, or “did you know.”
- Write for spoken clarity, not essay completeness.
- One dominant claim per sentence.
- A visible payoff must occur within about two seconds of any explanatory claim.
- Do not narrate what is already perfectly obvious on screen; add mechanism, contrast, or implication.
- Use concrete verbs and familiar nouns.
- Prefer thresholds and reversals over exhaustive lists.
- Reserve at least three non-obvious consequences for after the first third.
- End immediately after the conceptual payoff. Calls to action belong in the caption or pinned comment.

## 11. Scene Generation Prompt Schema
Generate each scene separately. Prompts must describe the starting state, transformation, and ending state—not merely the scene’s topic.
| Prompt field | Required detail |
| --- | --- |
| Continuity anchor | Exact Bolt design, clothing/suit, proportions, face, and persistent damage |
| Starting state | Pose, object positions, environment, and emotional baseline |
| Trigger | The force or event that begins the scene |
| Transformation | What physically changes on screen |
| Bolt performance | Eyes, posture, hands, balance, speed, and emotional reaction |
| Object interaction | What Bolt touches, tries to use, breaks, carries, avoids, or escapes |
| Ending state | The final pose and damaged/changed environment for the next cut |
| Camera | Shot size, movement, angle, and focal subject |
| Lighting/environment | Mood and depth cues |
| Duration | Expected usable clip length |
| Negative prompt | Specific static, generic, comedic, or semantically wrong outputs to avoid |


### 11.1 Prompt formula
| Copy-paste structure [Character continuity]. Begin with [starting state]. When [trigger] occurs, [transformation]. Bolt reacts by [specific performance]. He interacts with [familiar object] by [verb]. The camera [movement/composition]. End with [ending state]. The action must be readable without narration. Avoid [specific failure modes]. |

## 12. Visual Variation and Semantic Change
| Dimension | Constraint |
| --- | --- |
| Semantic change | New action, consequence, object relationship, transformation, danger, solution, or scale comparison every 1.5–3 seconds |
| Mini-payoff | At least every 3–5 seconds |
| Premise reset | Every 10–15 seconds when runtime supports it |
| Consecutive framing | No two adjacent scenes with the same shot size and Bolt placement |
| Consecutive emotion | No more than three scenes with the same emotional mode |
| Consecutive consequence | No adjacent scenes proving the same type of failure |
| Object interaction | At least 60% of scenes should contain a meaningful interaction |
| Silent comprehension | At least 80% of the narrative should remain clear when muted |

## 13. Editing, Audio, and Caption Specification
| Area | Rule |
| --- | --- |
| Opening | Meaningful action begins in the first frame; premise validated by 0.7 seconds |
| Cuts | Cut on action, transformation, revelation, or emotional change—not arbitrary time intervals |
| Shot length | May be longer when substantial action evolves inside the shot |
| Music | Escalate by story chapter; avoid one unchanging bed |
| Pattern interrupts | Use strategic silence, POV shift, cutaway, scale inversion, speed ramp, or new environment |
| SFX | Emphasize causes and impacts; do not attach a whoosh to every cut |
| Captions | One to four words per unit; synchronize the emphasized word to the visible event |
| On-screen data | Use only when the number improves understanding; never substitute it for action |
| End screen | Maximum approximately 0.8 seconds; no static CTA |
| Runtime | Continue only while the next scene adds a distinct high-value consequence |


## 14. Production Workflow
1. Score the topic. Reject or restructure ideas below the threshold.
1. Define the governing rule, Bolt objective, hidden consequences, scientific assumptions, and final payoff.
1. Create the consequence ladder, world map, emotion map, and mini-payoff ledger.
1. Generate and score three hook variants.
1. Lock the final transcript.
1. Build the beat-by-beat storyboard and scene-value scores.
1. Write individual scene prompts with beginning and ending states.
1. Create a low-cost animatic using stills, temp narration, captions, and sound cues.
1. Run the adversarial retention audit, mute test, predictability test, and science test.
1. Generate final video clips only after the animatic passes.
1. Edit, caption, mix audio, and run final render QA.
1. Publish one packaging variant and record early analytics.
1. Update the learning log and incorporate new rules into the next spec.
## 15. Animatic and Final-Render Audits
### 15.1 Adversarial retention score
| Category | Weight | Pass condition |
| --- | --- | --- |
| First-frame stopping power | 15 | Immediate, readable event |
| Promise-stack range | 10 | Opening previews multiple consequence categories |
| Audio–visual proof | 15 | Every major claim is visibly demonstrated |
| Mini-payoff density | 15 | Reward every 3–5 seconds |
| Consequence variety | 10 | No repetitive failure ladder |
| World/premise resets | 10 | Operating rules change at meaningful thresholds |
| Bolt acting/object interaction | 10 | Emotion and verbs remain legible |
| Predictability control | 5 | Remaining structure is not obvious by one-third |
| Silent comprehension | 5 | At least 80% understood muted |
| Final payoff | 5 | Climax is strongest and conceptually memorable |


Minimum animatic production score: 82/100. Minimum final-render score: 88/100.
### 15.2 Automatic rejection criteria
- The opening is a title card, calm setup, or already-completed result rather than active consequence.
- Bolt remains emotionally neutral while danger, injury, confusion, or transformation is narrated.
- A label, gauge, color change, or progress bar is the only evidence of the claim.
- Two consecutive scenes use the same composition, consequence category, or emotional beat.
- The climax is visually weaker or less original than an earlier scene.
- A familiar-object metaphor changes the meaning, becomes clip-art, or reads as accidental comedy.
- A scene is understandable only because the narrator explains it.
- The viewer can accurately predict every remaining beat by the first third.
- The final card exceeds approximately 0.8 seconds or repeats the narration without adding payoff.
- The video continues after it has exhausted meaningful new consequences.
## 16. Scene-Value Score and Pruning
Score every planned scene from 0–5. Minimum scene score: 17/25. Scenes below the threshold must be cut, combined, or redesigned.
| Dimension | Question |
| --- | --- |
| Novelty | Does this introduce a new consequence or category? |
| Visual proof | Can the claim be understood without narration? |
| Bolt agency | Does Bolt try, react, choose, fail, or adapt? |
| Emotional shift | Does the beat change or intensify the emotional mode? |
| Forward pull | Does it create a concrete reason to watch the next scene? |

### 17.1 Diagnostic map

| --- | --- | --- |
| Poor viewed rate, strong retention | Packaging or opening-frame mismatch | Rewrite title/thumbnail/hook while preserving core story |

## 18. Worked Architecture Example: Gravity +1% Every Second
| Field | Example |
| --- | --- |
| Governing rule | Gravity rises continuously by 1% each second |
| Bolt objective | Cross a room and reach an emergency cutoff switch |
| Hook promise stack | Bolt hits the floor; car suspension snaps; skyscraper steel bends |
| Early consequence | Backpack and limbs become noticeably heavier |
| Daily-life mini-payoff | Chair collapses when Bolt tries to stand |
| Unexpected advantage | Bolt briefly gains traction and cannot be knocked backward |
| Reversal | His heart cannot maintain blood flow to the brain |
| World reset | Room → street → internal body cutaway → city-scale destruction |
| Final payoff | Gravity does not need to flatten Bolt; it only needs to stop circulation |
| Loop | Bolt reaches for cutoff switch; cut back to first impact before contact |


### 18.1 Example consequence ladder
| Time | Scene | Mini-payoff | Open loop |
| --- | --- | --- | --- |
| 0–3s | Three-image catastrophe montage | Immediate danger and visual range | How fast did this happen? |
| 3–7s | Reset to +1%; Bolt runs to cutoff | Clear objective | Can he reach it? |
| 7–11s | Backpack drags him down; chair snaps | Physical comedy/failure | What fails next? |
| 11–15s | Temporary traction advantage | Unexpected benefit | When does it turn dangerous? |
| 15–20s | Internal cutaway: heart strains | Category change | Will circulation fail first? |
| 20–25s | Bolt loses vision before being flattened | Counterintuitive failure | What happens to the city? |
| 25–31s | Cars, bridges, and buildings deform | Scale climax | Concept resolved |
| 31–32s | Payoff line + loop | Memorable mechanism | Returns to hook |

## 20. Master Principle
| The standard for every Bolt Short The viewer should never remain only to receive more information. They should remain because the previous consequence was satisfying, the next consequence is difficult to predict, and Bolt is actively struggling through a changing world. |
| --- |


This system cannot guarantee a specific retention percentage. It is designed to remove preventable failures: static AI staging, fact-list fatigue, weak visual proof, predictable escalation, repeated compositions, unclear metaphors, and expensive full renders built from an untested structure.
