# Optional video-engine instructions

Read `../docs/VIDEO_ENGINE_WORKBENCH.md` before installing, operating or modifying
anything in this directory. Root `AGENTS.md` remains authoritative for paid runs.

- MoneyPrinterTurbo is a separate stock/hybrid Shorts flow.
- Motion Canvas is a reusable scene feature, not a replacement orchestrator.
- OpenShorts repurposes an owned finished artifact; it is not our publishing service.
- ViMax-compatible descriptions belong to the shared draft storyboard feature.
- CI install/import/build success is not live deployment or a production-ready flow.
- Keep upstream dependencies isolated. Never import their full apps into `app.py`.
- Installation, examples, CLI validation and imports authorize no provider spend.
- Do not enable auto-upload, cloud billing or external galleries.
- Preserve exact source pins; do not silently update to latest.
- The deployed static workbench has no DB persistence. Export drafts explicitly.
- Consult each smoke report's scope; OpenShorts cut_clip is not a full clipping pilot.
