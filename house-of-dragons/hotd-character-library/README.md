# House of the Dragon Character Library

Reusable animated-style character masters for **The Dragon Council**.

## Locked visual system

- Mature, high-end stylized 3D animation for a serious medieval political drama
- Realistic age-appropriate proportions and recognizable facial identity
- Square character master, one character only, framed from head to mid-thigh
- Clean charcoal-gray studio background with a subtle vignette
- Soft cool key light from front-left and warm amber rim light from rear-right
- Tactile, hand-painted treatment of skin, hair, cloth, leather, jewelry, and metal
- Character-specific faces, hair, costumes, ancestry, age, and accessories derived from the supplied reference image
- No text, scenery, extra characters, invented heraldry, exaggerated eyes, chibi proportions, or glossy toy treatment

These are static master renders, not rigged 3D models. Use them as the identity source for future expression variants, action poses, diagrams, thumbnails, parallax animation, or image-to-video shots.

## Continuity rule for future renders

Always supply the relevant master as the authoritative identity reference. Change only pose, expression, camera angle, or scene requirements. Preserve the face, apparent age, body proportions, ancestry, hairstyle, signature costume silhouette, and defining accessories unless the script explicitly requires a canonical costume change.
